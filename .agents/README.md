# .agents

## Purpose

Espacio reservado para metadatos locales de agentes cuando una herramienta lo
requiera.

## Who Uses This Folder

- Local agent tooling only when explicitly configured.
- Context Keeper when local agent metadata must be explained.

## Contains

- Future local agent state or metadata if explicitly required.

## Never Contains

- Product documentation authority.
- Source code.
- Business logic.
- Credentials or tokens.
- Sprint deliverables.

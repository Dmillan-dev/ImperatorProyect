# demos

Status: **HISTORICAL VISUAL PROTOTYPES / NOT THE CERTIFIED MVP DEMO**

## Purpose

Demonstration artifacts for explaining IMPERATOR outside the production
implementation.

## Who Uses This Folder

- Product Guardian for narrative and demonstration review.
- Context Keeper to keep demos separate from production code.

## Contains

- Static demo assets.
- Visual prototypes.
- Non-production explanatory screens.

The current evidence-backed demonstration control lives in
`../docs/demos/README.md`. The executable local product proof is documented in
`../docs/demos/45_End_To_End_Business_Value_Demo.md`.

## Never Contains

- Production frontend source.
- Backend services.
- Domain logic.
- Database migrations.
- Secrets or customer data.

## Commercial Restriction

Do not present these static screens as current product behavior. They include
portfolio views, aggregate company savings, multiple Decisions, historical
outcome claims and integration surfaces that exceed the current one-case MVP.
They may be used only to discuss historical product direction, clearly labeled
as a non-functional concept.

# demos

## Purpose

Artefactos demostrativos para explicar IMPERATOR visualmente antes o fuera de
la implementacion productiva.

## Who Uses This Folder

- Product Guardian for narrative and demonstration review.
- Context Keeper to keep demos separate from production code.

## Contains

- Static demo assets.
- Visual prototypes.
- Non-production explanatory screens.

## Never Contains

- Production frontend source.
- Backend services.
- Domain logic.
- Database migrations.
- Secrets or customer data.

# services/frontend

Scaffold for Decision Review Workspace first, with Executive Workspace / Decisions / Ledger surfaces as expansion context (React / Next.js).

Phase 0 note: this folder is documentation/scaffold only. Do not add runnable frontend app code, package manifests or production UI implementation until Phase 1 is explicitly approved and logged.

Tasks:
- Component library plan and design tokens for the Decision ROI Platform.
- Conceptual adapter layer for future backend APIs (gRPC-web or HTTP bridge).
- MVP product surface: Decision Review Workspace.
- Expansion surfaces: Executive Workspace, Decisions, Decision Ledger, Business Value and Integrations.
- Target stack context: Next.js, React, TypeScript, Tailwind CSS and shadcn/ui or equivalent.
- Follow `docs/architecture/21_Technical_Architecture_Context.md` before proposing frontend structure.
- Follow `docs/architecture/31_MVP_Implementation_Standard.md` before expanding beyond the first Decision Review Workspace.
- Follow `docs/architecture/32_Phase_1_MVP_Scope_and_Exit_Criteria.md`; the first UI must support one Decision ROI Case, one recommendation and the Phase 1 exit criteria.

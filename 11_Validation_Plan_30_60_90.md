# 11 — Validation Plan 30/60/90

## Days 0–30: Validate Problem and Priority

- interview Platform/Security/CTO profiles
- confirm top pain and customer language
- validate initial buying signals

## Days 31–60: Validate Narrative and Solution Framing

- test messaging by buyer persona
- refine positioning and differentiation
- tighten wedge definition

## Days 61–90: Validate Commercial Viability

- test land-and-expand plausibility
- refine pricing logic hypotheses
- decide readiness for Phase 1 (product design)

## Go/No-Go Criteria

Go if all are true:
- strong recurring pain,
- clear buyer path,
- defensible value linked to measurable KPIs.

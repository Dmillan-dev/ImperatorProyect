# samples

## Purpose

Controlled sample cases for validating MVP flows without mixing real data,
visual demos or production code.

## Who Uses This Folder

- Product Guardian to validate MVP evidence scenarios.
- Implementation Agent only when a sprint authorizes fixtures or samples.
- Quality Agent to verify that samples match acceptance contracts.

## Contains

- Approved sample cases.
- Fixture boundaries derived from canonical evidence documents.

## Never Contains

- Production code.
- Customer data.
- Credentials or tokens.
- Evidence invented outside approved documentation.
- New MVP scope.

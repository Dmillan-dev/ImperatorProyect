# samples

## Purpose

Casos de muestra controlados para validar flujos del MVP sin mezclar datos
reales, demos visuales ni codigo productivo.

## Who Uses This Folder

- Product Guardian to validate MVP evidence scenarios.
- Implementation Agent only when a sprint authorizes fixtures or samples.
- Quality Agent to verify that samples match acceptance contracts.

## Contains

- Future approved sample cases.
- Future fixture boundaries derived from canonical evidence documents.

## Never Contains

- Production code.
- Customer data.
- Credentials or tokens.
- Evidence invented outside approved documentation.
- New MVP scope.

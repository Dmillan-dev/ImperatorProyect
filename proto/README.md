# proto

## Purpose

Internal or experimental communication contracts when explicitly authorized by
architecture.

## Who Uses This Folder

- Architecture Guardian to verify service contract boundaries.
- Implementation Agent only when a sprint authorizes protocol work.
- Quality Agent to review compatibility once generated artifacts are allowed.

## Contains

- Protocol contract files.
- Future versioned interface definitions if explicitly authorized.

## Never Contains

- Generated source code.
- Business logic.
- Runtime services.
- Provider secrets.
- Database schema authority.

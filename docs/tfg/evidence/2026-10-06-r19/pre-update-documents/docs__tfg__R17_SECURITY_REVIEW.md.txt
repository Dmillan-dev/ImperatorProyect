transitive** paths: 1.1.18 and 5.0.9. They were not introduced by the Next patch;
the lockfile comparison shows that the initial patch changed only Next/env/SWC.
Advisories concern recursive/quadratic expansion of untrusted glob patterns:
[nested expansion](https://github.com/juliangruber/brace-expansion/security/advisories/GHSA-qhr7-859c-m2p7),
[comma parsing](https://github.com/juliangruber/brace-expansion/security/advisories/GHSA-6j4f-fj2g-mc7p),

CVE-2026-102276 and CVE-2026-102278 in each installed copy. No product route
accepts glob patterns. These dependencies serve local
lint/test tooling, not the deployed standalone application. Runtime absence
must be read from the new image scan, not inferred from the dev flag alone.

A separately prepared proposal changes only those locked copies to **1.1.21
and 5.0.12**, preserving every direct dependency. Its isolated npm audit is
zero. Applying it is pending the founder's scope decision because the current
instruction expressly limits updates to the five original R-17 findings.
It is not applied silently and does not justify weakening a failing audit.

## Existing Controls And Their Limits

- **M1:** Canonical Compose exposes frontend only at 127.0.0.1; backend and PostgreSQL have no published host ports. PostgreSQL uses only internal data network. Academic scope requires synthetic data; loopback does not block a malicious local user/browser or an already compromised container.
- **M2:** Frontend uid1000/cap_drop ALL; PostgreSQL image uid999 and five allowed capabilities CHOWN,DAC_OVERRIDE,FOWNER,SETGID,SETUID; neither grants SYS_ADMIN. Both read_only and no-new-privileges. Writable tmpfs/database volume and SUID files still exist. These controls limit privilege paths; they do not repair memory corruption.
- **M3:** Application import uses NDJSON/JSON and Java prepared statements; dynamic sort names map to fixed enumerated SQL fragments. No reviewed public route accepts raw SQL, XML, SQLite databases, Perl programs or OS command strings. Static review is not proof against unknown bugs or stolen DB credentials.
- **M4:** No fstab entries authorizing user mounts, no systemd-homed daemon/managed users, no Python/libxml2 SAX bindings in reviewed images. Absence is scoped to these exact inspected image files/configuration.
- **M5:** Existing Compose CPU/memory/PID limits: frontend0.5CPU/512MiB/100PIDs, PostgreSQL1CPU/1024MiB/200PIDs. These bound some resource exhaustion; they do not guarantee service availability or prevent leaks/code execution.
- **M6:** Versioned PostgreSQL initialization directory is empty; Compose does not mount untrusted init archives and uses uncompressed versioned Flyway SQL. LDAP is not configured (SCRAM host authentication). PostgreSQL TCP/TLS use does not enable DTLS. Operator changes to any of these assumptions invalidate this review.

## Vendor Fix Availability

All23 reviewed Bookworm source records are open without a listed fixed Bookworm version in the [fresh vendor selection](vendor-status.json). Some fixes exist in upstream/newer suites; this does not make them a tested, compatible or authorized Bookworm patch. MiniZip is a source-association finding for code not built into the inspected Debian zlib package. Do not interpret vendor deferral as exploitability evidence.

For OpenSSL DTLS, the [upstream advisory](https://openssl-library.org/news/secadv/20260929.txt) names the3.0.23 premium-support fix; Debian currently lists its public Bookworm security candidate as vulnerable. For ACL, the [Debian note](https://security-tracker.debian.org/tracker/CVE-2026-54369) explains the new ABI/backport boundary. These examples support a bounded temporary decision, not a claim that fixes never exist.

PostgreSQL documents [SQL/XML functions](https://www.postgresql.org/docs/18/functions-xml.html), [TLS over TCP](https://www.postgresql.org/docs/18/ssl-tcp.html) and [LDAP configuration](https://www.postgresql.org/docs/18/auth-ldap.html). Actual image linkage/configuration and repository business routes determine the assessments above.

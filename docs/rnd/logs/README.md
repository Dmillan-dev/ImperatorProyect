# R&D Activity Logs

## Purpose

This folder is reserved for future monthly activity logs.

Create one file per month only when real tracked work exists.

Recommended naming:

```text
YYYY-MM_ACTIVITY_LOG.md
```

Example:

```text
2026-07_ACTIVITY_LOG.md
```

## Rules

- Do not invent historical hours.
- Do not group unrelated work under one vague item.
- Link every activity to a work package.
- Link every activity to a document, decision, code change, test, experiment or review artifact.
- Separate routine work from I+D/i candidate work.
- Preserve failed attempts and negative results when they reveal technical uncertainty.

## Minimum Monthly Contents

Each monthly log should include:

1. month,
2. contributors,
3. activity table,
4. hours by work package,
5. artifacts produced,
6. tests or experiments run,
7. decisions recorded,
8. unresolved technical uncertainty,
9. routine/non-I+D work separated,
10. reviewer sign-off.

# 09 — Business Model Hypotheses

## Initial Monetization Hypotheses

Possible pricing axes:
1. number of validated Decision ROI Cases,
2. recovered value validated through ledger outcomes,
3. recurring recovery reviews,
4. compliance/audit package tier after ledger history exists.

Connector count should not be the main value axis for the MVP. The product should be priced and validated around recovered operational value and approval-ready recommendations.

## Defensible Value Unit

Value is created through:
- recovered operational value,
- decision-level hidden-cost reduction,
- investigation effort reduction,
- audit-effort reduction.

The preferred value unit for MVP validation is one **Decision Recovery Workflow** with current monthly cost, evidence, recommendation, approval decision and later result validation.

The primary MVP value pool is:
- AI model downgrade or change

Expansion value pools:
- unused AI agent removal
- underutilized AWS resource optimization tied to the same Decision ROI Case
- negative-ROI feature review
- duplicated service or agent consolidation

## Willingness-to-Pay Hypothesis

Strongest in organizations with:
- AWS-first cloud spend with future multi-cloud complexity,
- compliance pressure,
- rapidly growing AI usage.

The strongest commercial proof is an approved Decision ROI Case with validated realized value. A Business Value page becomes useful after several validated outcomes exist.

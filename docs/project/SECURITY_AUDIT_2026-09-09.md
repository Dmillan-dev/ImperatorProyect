# Security And Maintenance Audit - 2026-09-09

Status: **LOCAL PASS / HOSTED HISTORY AND D096 UPSTREAM GATES PENDING**

## Scope

This audit covers the current working tree, dependency locks, maintained Docker
images, Compose configuration, CI security controls and active documentation.
It does not inspect customer systems, use customer data, claim a penetration
test or weaken any D096 release gate.

Evidence generated by local tools is retained under the ignored
`build/security-audit` directory. Reports can contain package inventories and
must not be committed without a separate review.

- Current-tree Trivy secret scan: **0 findings**.
- Tracked runtime secret values: **none identified**.
- Runtime secret files and generated audit evidence remain ignored.
- Full Git-history Gitleaks scan: **hosted result pending**.

The local Gitleaks container was not given repository access because that would
allow an untrusted third-party image to read ignored local secret files. The
Security workflow now downloads the official Gitleaks 8.30.1 Linux binary,
verifies its exact SHA-256 checksum, checks out full history and scans with
redaction. No clean-history claim is made before that hosted job passes.

## 🚀 Featured Project

### [IMPERATOR — Decision Intelligence & Governance](https://github.com/Dmillan-dev/ImperatorProyect)

A **local academic MVP** that connects operational evidence to deterministic recommendations, human approval and validated outcomes. It helps engineering, finance and audit teams reconstruct **why a change was proposed, who authorized it and whether it delivered the expected value**.

- **Core workflow:** Evidence → Decision → Recommendation → Human Review → append-only Decision Ledger → Business Value.
- **Architecture:** Java 21 / Spring Boot modular monolith with hexagonal boundaries, PostgreSQL / Flyway persistence and a Next.js Decision Review Workspace.
- **Demonstrated locally:** one synthetic case, four roles, JWT/RBAC, database persistence and recovery, backend/integration/frontend tests and a real Docker rehearsal.
- **Security & delivery:** hardened images, GitHub Actions, Trivy, Gitleaks and CodeQL; residual-risk decisions remain explicit and bound to identified artifacts.
- **Cloud preparation:** read-only GitHub/AWS evidence adapters, Terraform and OIDC workflows for a future ECS/Fargate and RDS pilot. An optional Bedrock explanation adapter is implemented and tested offline; business decisions remain deterministic and human-controlled.

**Current stage: local MVP / pre-pilot.** Final security approval, academic version closure and a narrated defence remain pending. Live AWS deployment and provider validation are future gates.

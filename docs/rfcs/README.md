# RFCs

Place RFC and feature proposals here. Use clear status headers: `Proposed`, `Accepted`, `Deprecated`.

Recommended files:
- `docs/rfcs/0001-some-feature.md`

Architecture Decision Records live in `docs/decisions/adr/`.

Architecture RFCs should reference:
- `docs/product/20_MVP_Decision_ROI_Platform_Blueprint.md` for product boundary.
- `docs/architecture/21_Technical_Architecture_Context.md` for target architecture context.
- `docs/architecture/18_Architecture_Thesis.md` for conceptual architecture thesis.

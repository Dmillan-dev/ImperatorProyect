## Use

1. Publish from the founder/student personal LinkedIn profile.
2. Lead with the problem and interview request, not the architecture.
3. Label the workspace and financial values as synthetic demonstration data.
4. Use the first conversation for discovery; show L1 only after a concrete relevant case appears.

## Research Method

Start with 10-15 semi-structured interviews. Use a survey only afterwards to
quantify patterns already discovered in those conversations. Interviews reveal
the workflow, language, economic impact and decision owner; a survey alone is
unlikely to uncover those details at this stage.
